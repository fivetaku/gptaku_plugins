# tikeytaka:sync — 볼트 → 프로젝트 전파

코어 CLI: `bash "${CLAUDE_PLUGIN_ROOT}/bin/tkt"` (이하 `tkt`)

```bash
tkt sync --check   # 1) 드라이런: 무엇이 바뀔지 먼저 확인
tkt sync           # 2) 실제 전파
```

- 볼트 암호 불일치·손상은 sync가 시작 전에 명시적 에러로 중단된다(조용히 진행되지 않음). 드라이런 결과가 예상 밖으로 많으면 매핑 오류나 .env 따옴표/중복 정의 차이 신호일 수 있으니 실행 전에 사용자에게 확인한다.
- 전파 후 변경 건수만 보고한다. 값은 출력하지 않는다.
- 이미 떠 있는 프로세스(서버·데몬)는 재시작해야 새 키를 읽는다는 점을 변경이 있었을 때만 한 줄로 알린다.
