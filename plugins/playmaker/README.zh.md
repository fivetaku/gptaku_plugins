# playmaker (플레이메이커)

<p align="center">
  <img src="assets/playmaker-hero-01.png" alt="playmaker" width="320">
</p>

> **Claude Code 内的实时目标看板 — 一眼看清目标进展到哪里、正在做什么、哪些在等你处理。**

goaljaby 负责进球,playmaker 负责读懂整场比赛。playmaker 是一个 Claude Code mod:它读取 goaljaby 目标文件夹中的 `PLAN.md` 和 `PROGRESS.md`,在侧边面板中绘制 **等待 · 进行中 · 完成** 看板。每张卡片对应一个任务并带有里程碑标签,需要人工处理的任务标为 ⏸,输入框上方显示一行摘要。

[快速开始](#快速开始) • [你会看到什么](#你会看到什么) • [读取的格式](#读取的格式) • [命令](#命令) • [环境要求](#环境要求)

## 快速开始

### 1. 添加插件市场

```
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
```

### 2. 安装

```
/plugin install playmaker
```

### 3. 重启 Claude Code

### 4. 打开看板

```
/playmaker
```

playmaker 会在当前文件夹向下两层内查找,打开最近修改的目标文件夹。如果有正在进行且最近 7 天内修改过的目标,会话开始时看板会自动打开。

## 你会看到什么

```
인증까지 붙인 MVP를 배포한다.
골 1/3 · 진행 M2 · 작업 2/6 · ⏸ 사람 대기 1
[마일스톤별 보기] [완료 펼치기]

대기 (2)                 진행 (2)                      완료 (2)
· [M2] 마일스톤 검증 실행  ▶ [M2] OAuth 콜백을 연결한다   ✓ M1 2건
· [M3] 배포 설정을 만든다  ⏸ [M2] 운영자 승인 계정 대기
```

v0.1 的看板标签为韩语(대기 = 等待,진행 = 进行中,완료 = 完成,골 = 目标,작업 = 任务,사람 대기 = 等待人工)。任务文本按 PLAN.md 原文显示,任何语言均可。

- **三个状态列。** 每张卡片一个任务,带有 `[M2]` 这样的里程碑标签。多个里程碑同时进行时都会显示。
- **人工等待单独标出。** 标记为 `[!]` 的任务,或旧格式中进度记录写明在等人的里程碑,显示为 ⏸。
- **窄面板纵向堆叠。** 宽度不足 72 列时按 进行中、等待、完成 自上而下排列,完成列折叠为各里程碑的数量。
- **按里程碑查看。** 一个按钮即可切换为每个里程碑的清单(`[ ] [>] [x] [!]`)。
- **实时更新。** PLAN.md 或 PROGRESS.md 的修改会在 3 秒内显示。
- **在卡片上直接下指令。** 点击卡片后,下方会按任务状态展开操作按钮:等待人工的任务有 批准并继续 / 我需要确认什么? / 暂缓,进行中的任务有 进展如何? / 有没有卡住?,还可以用 **直接输入…** 发送自己的话。指令带着任务 ID 直接进入当前会话。会话回答完之前其他卡片会被锁定,避免相反的指令接连进入。playmaker 依然不修改 PLAN.md,标记由代理更新。
- **在浏览器中打开 · 关闭。** 面板上的 **在浏览器中打开** 按钮会启动网页看板并用默认浏览器打开,同时在面板中留下可点击的链接。**✕ 关闭** 会同时收起面板和输入框上方的摘要行,用 `/playmaker` 可再次打开。
- **不一致提醒。** PLAN 清单与 PROGRESS 说法不一致时,看板用 ⚠ 提示,而不是猜测。

## 读取的格式

| 目标文件夹 | 任务状态来源 |
|---|---|
| goaljaby 0.7+ | PLAN.md 中每个里程碑的清单:`- [>] M2-T1: 任务`(`[ ]` 等待 · `[>]` 进行中 · `[x]` 完成 · `[!]` 需要人工) |
| goaljaby 0.6 及更早、手写的 PLAN | 根据 PROGRESS.md 的里程碑状态和该里程碑的 Scope 行推断。推断出的卡片以淡色显示 |

表格形式的 PLAN(`| M1a 名称 | 范围 |`)和 `### M2 名称` 标题同样可以读取。playmaker 只读取文件,不会向目标文件夹写入任何内容。

## 命令

| 命令 | 作用 |
|---|---|
| `/playmaker` | 在当前文件夹下查找最近的目标文件夹并打开看板 |
| `/playmaker <文件夹>` | 打开指定目标文件夹的看板 |
| `/playmaker web [文件夹]` | 启动浏览器看板(见下文)并给出地址 |

该命令同时返回文本摘要,因此在无法绘制面板的环境中也有用。

## 环境要求

- [Claude Code](https://code.claude.com/docs/en/plugins/mods/overview) **v2.1.287+**(mods),终端或桌面应用的 Code 标签页
- 在终端中,面板需要 `/tui fullscreen` 且宽度 110 列以上才会停靠在对话旁;否则显示在输入框上方
- 无法绘制面板的宿主(Paseo、`claude -p`、VS Code 聊天、云端会话)中,`/playmaker` 返回文本摘要,`/playmaker web` 则以本地网页提供同一看板(仅 127.0.0.1,每 2 秒刷新,需要 Node 22.18+)
- **Paseo:** playmaker 会识别出自己运行在 Paseo 中,有进行中的目标时自动启动网页看板并以 Paseo 浏览器标签打开(之后复用该标签,只需拖到右侧分栏一次)。在网页看板上方选择正在处理该目标的 Paseo 会话后,点击卡片即可向它发送相同的操作
- 终端中鼠标点击需在 `/tui fullscreen` 下使用;否则按 Ctrl+X 再按 Tab 进入面板,用方向键和 Enter 选择

### 搭配使用效果最佳

| 插件 | 增加的功能 |
|--------|--------------|
| `goaljaby` 0.7+ | 记录 playmaker 读取的逐任务清单 |
