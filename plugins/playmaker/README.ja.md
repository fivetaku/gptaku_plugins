# playmaker (플레이메이커)

<p align="center">
  <img src="assets/playmaker-hero-01.png" alt="playmaker" width="320">
</p>

> **Claude Code の中で見るゴール進行ボード — 今どこまで進み、何をしていて、何があなたを待っているかがひと目でわかります。**

goaljaby がゴールを決め、playmaker が試合全体を読みます。playmaker は Claude Code の mod で、goaljaby のゴールフォルダにある `PLAN.md` と `PROGRESS.md` を読み、サイドパネルに **待機 · 進行中 · 完了** のボードを描きます。カード1枚が作業1つで、マイルストーンのタグが付き、人の対応が必要な作業は ⏸ で示され、入力欄の上に1行の要約が表示されます。

[クイックスタート](#クイックスタート) • [表示される画面](#表示される画面) • [読み取る形式](#読み取る形式) • [コマンド](#コマンド) • [必要条件](#必要条件)

## クイックスタート

### 1. マーケットプレイスを追加

```
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
```

### 2. インストール

```
/plugin install playmaker
```

### 3. Claude Code を再起動

### 4. ボードを開く

```
/playmaker
```

現在のフォルダから2階層下まで探し、最も最近更新されたゴールフォルダを開きます。進行中で直近7日以内に更新されたゴールがあれば、セッション開始時にボードが自動で開きます。

## 表示される画面

```
인증까지 붙인 MVP를 배포한다.
골 1/3 · 진행 M2 · 작업 2/6 · ⏸ 사람 대기 1
[마일스톤별 보기] [완료 펼치기]

대기 (2)                 진행 (2)                      완료 (2)
· [M2] 마일스톤 검증 실행  ▶ [M2] OAuth 콜백을 연결한다   ✓ M1 2건
· [M3] 배포 설정을 만든다  ⏸ [M2] 운영자 승인 계정 대기
```

v0.1 ではボードのラベルは韓国語です(대기 = 待機、진행 = 進行中、완료 = 完了、골 = ゴール、작업 = 作業、사람 대기 = 人の対応待ち)。作業テキストは PLAN.md に書かれたとおりに、どの言語でも表示されます。

- **状態3列。** カード1枚が作業1つで、`[M2]` のようにマイルストーンのタグが付きます。複数のマイルストーンが同時に進行中でもすべて表示されます。
- **人の対応待ちは別表示。** `[!]` が付いた作業や、旧形式で進捗記録に人を待っていると書かれたマイルストーンは ⏸ で表示されます。
- **狭い幅では縦に。** 72列未満では 進行中、待機、完了 の順に縦に並び、完了はマイルストーンごとの件数に折りたたまれます。
- **マイルストーン別表示。** ボタン1つでマイルストーンごとのチェックリスト(`[ ] [>] [x] [!]`)に切り替わります。
- **リアルタイム。** PLAN.md や PROGRESS.md の変更は3秒以内に反映されます。
- **カードから直接指示。** カードを押すと、その下に作業状態ごとの操作ボタンが開きます。人の対応待ちの作業なら 承認して進める / 何を確認すればいい? / 保留、進行中なら 進捗を教えて / 詰まっていない? といった具合で、**直接書く…** で自由な指示も送れます。指示は作業 ID 付きで今のセッションにそのまま入ります。セッションが答え終わるまで他のカードはロックされ、逆の指示が続けて入ることはありません。playmaker は引き続き PLAN.md を書き換えず、マーカーはエージェントが更新します。
- **ブラウザで開く · 閉じる。** パネルの **ブラウザで開く** ボタンはウェブボードを起動して既定のブラウザで開き、パネルにクリックできるリンクを残します。**✕ 閉じる** はパネルと入力欄上の要約行をまとめて閉じ、`/playmaker` で再び開けます。
- **不一致の警告。** PLAN のチェックリストと PROGRESS の内容が食い違うと、推測せずに ⚠ で知らせます。

## 読み取る形式

| ゴールフォルダ | 作業状態の出どころ |
|---|---|
| goaljaby 0.7 以上 | PLAN.md のマイルストーンごとのチェックリスト `- [>] M2-T1: 作業`(`[ ]` 待機 · `[>]` 進行中 · `[x]` 完了 · `[!]` 人の対応待ち) |
| goaljaby 0.6 以前、手書きの PLAN | PROGRESS.md のマイルストーン状態とそのマイルストーンの Scope 行から推定します。推定したカードは淡く表示されます |

表形式の PLAN(`| M1a 名前 | 範囲 |`)や `### M2 名前` の見出しも読み取ります。playmaker はファイルを読むだけで、ゴールフォルダには何も書き込みません。

## コマンド

| コマンド | 内容 |
|---|---|
| `/playmaker` | 現在のフォルダ以下で最新のゴールフォルダを探してボードを開きます |
| `/playmaker <フォルダ>` | 指定したゴールフォルダのボードを開きます |
| `/playmaker web [フォルダ]` | ブラウザ版ボード(下記)を起動してアドレスを返します |

コマンドはテキスト要約も返すので、パネルを描けない環境でも役に立ちます。

## 必要条件

- [Claude Code](https://code.claude.com/docs/en/plugins/mods/overview) **v2.1.287 以上**(mods)、ターミナルまたはデスクトップアプリの Code タブ
- ターミナルでパネルを会話の横に固定するには `/tui fullscreen` と110列以上が必要です。それより狭いと入力欄の上に表示されます
- パネルを描けないホスト(Paseo、`claude -p`、VS Code チャット、クラウドセッション)では `/playmaker` がテキスト要約を返し、`/playmaker web` で同じボードをローカルのウェブページとして見られます(127.0.0.1 のみ、2秒ごとに更新、Node 22.18 以上)
- **Paseo:** Paseo 上で動いていることを自ら検知し、進行中のゴールがあればウェブボードを起動して Paseo のブラウザタブで開きます(次回からはそのタブを再利用するので、右の分割に一度移すだけです)。ウェブボード上部でゴールを担当している Paseo セッションを選ぶと、カードから同じ操作をそのセッションに送れます
- ターミナルでのマウスクリックは `/tui fullscreen` で使えます。それ以外では Ctrl+X の後 Tab でパネルに入り、矢印キーと Enter で選びます

### 一緒に使うと便利なプラグイン

| プラグイン | 追加される機能 |
|--------|--------------|
| `goaljaby` 0.7+ | playmaker が読む作業ごとのチェックリストを記録します |
