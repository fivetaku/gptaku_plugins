# Changelog

## 0.1.0 (2026-10-13)

- 첫 버전. goaljaby 골 폴더의 PLAN.md·PROGRESS.md를 읽어 대기·진행·완료 보드(작업 카드 + 마일스톤 태그 + ⏸ 사람 대기)를 pane에 그린다. 프롬프트 위 한 줄 요약, `/playmaker [폴더]` 명령(텍스트 요약 포함).
- goaljaby 0.7+ 체크리스트(`[ ]`/`[>]`/`[x]`/`[!]`)를 읽고, 0.6 이하·사람이 쓴 PLAN은 마일스톤 상태와 범위에서 추정한다(흐린 카드).
- 72열 미만 세로 쌓기, 완료 접기, 마일스톤별 보기, 3초 폴링, PLAN·PROGRESS 불일치 ⚠.
- 화면이 없는 호스트용 웹 보기: `web/server.mjs`(의존성 없음, 127.0.0.1 전용, 2초 갱신, 6시간 무접속 시 종료). `/playmaker web [폴더]`로 켠다(Node 22.18+).
- Paseo 자동 감지(`PASEO_AGENT_ID`): 진행 중인 골이면 세션 시작 때 웹 보드를 켜고 Paseo `paseo` MCP로 브라우저 탭을 연다. 같은 주소 탭은 재사용, 옛 playmaker 탭은 주소만 옮긴다. 채팅에는 한 줄 요약만 남긴다.
- 웹 보기 디자인: Linear 방식(상단 바·마일스톤 다이아몬드 탭·상태 아이콘·3단 카드·리스트 보기·단축키 1/2/D), 로고 `assets/logo.svg`.
- 웹 보기 세션 연결(Paseo): 메시지를 받을 골 작업 세션을 고르고, 카드 상세 패널의 빠른 행동·직접 쓰기로 `paseo send`. 보낸 뒤 세션 답이 끝날 때까지 그 작업 행동 잠금. 쓰기 요청은 서버 토큰 + Origin 검사.
- 터미널 pane 카드 행동: 카드를 누르면 아래에 상태별 행동 줄과 직접 쓰기 입력칸(`Input`)이 펼쳐지고 `$.prompt.submit`으로 지금 세션에 지시한다. 턴이 끝날 때까지(`turn.complete`/`turn.abort`) 다른 카드 잠금. 대화상자는 쓰지 않는다.
- 터미널 pane 버튼: `브라우저로 열기`(웹 서버를 켜고 `open`으로 기본 브라우저, pane에 `Link` 남김), `✕ 닫기`(pane과 band 요약을 함께 내림).
- playmaker는 골 폴더에 쓰지 않는다. 마커 변경은 지시를 받은 에이전트가 한다.
