# Changelog

## [0.2.0] - 2026-10-21

### Added
- 사용자 라우트: `~/.claude/gptaku-core/routes.json`에 적은 개인 스킬(콜론 없는 이름)과 다른 마켓 플러그인 스킬도 gptaku 스킬과 같은 기준으로 지목한다. 같은 스킬이면 플러그인 라우트가 우선한다.
- `/gptaku-core:setup` 스킬과 `hooks/user_routes.py`(scan·write·remove·check·list): 설치된 스킬의 트리거 문구로 라우트 초안을 만들고, 승인 후 쓰고, 예문으로 점검한다.
- 잘못 쓴 사용자 파일은 훅을 멈추지 않는다: `{"routes": null}`은 무시하고, 빈 키워드나 빈 문자열에 맞는 패턴이 든 라우트는 다른 스킬을 가로채지 않도록 버린다. 읽을 수 없는 사용자 파일은 `write`·`remove`가 덮어쓰지 않는다.

### Fixed
- `…해줘: '인용문'`처럼 요청 뒤에 홑따옴표 인용이 붙으면 요청으로 보지 못하던 문제.
- `2.5로 그려줘`처럼 숫자와 점으로 시작하는 요청을 번호 목록으로 오인해 통째로 버리던 문제.
- `슬라이드 만들어줘 IR용으로`처럼 요청 동사 뒤에 짧은 보충어가 붙은 요청을 놓치던 문제(뒤가 다른 서술이면 여전히 요청으로 보지 않는다).
- `출첵`처럼 키워드 한 단어만 보낸 요청을 어미가 없다는 이유로 놓치던 문제.
