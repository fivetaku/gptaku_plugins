## 판정 — 동등

사전 등록 기준의 "**동등**: 통과율 차이가 미미 → 기능 유지하되 기본값 승격 안 함. 옵트인 실험 기능"에 해당한다.

3라운드 모두 **양 참가자가 게이트를 전부 통과**했다. 토너먼트가 고른 승자와 codex 단독의 산출물이
게이트 기준으로 구별되지 않는다. 그 대가로 CLI 호출이 2배 들었다.

**따라서:**
- 토너먼트를 어려운 태스크의 권장 기본값으로 승격하지 않는다
- `adopt: 'merge'`(Phase 4)를 **착수하지 않는다** — 승자 채택조차 값을 못 하는 상태에서 병합을 만들 근거가 없다
- 토너먼트는 사용자가 명시적으로 고를 때만 도는 옵트인 실험 기능으로 유지한다

---

## 판정에 반하는 관찰 (기록 의무)

결과가 "동등"이라고 해서 토너먼트가 무가치하다는 뜻은 아니다. 이 벤치가 못 본 것들:

1. **가장 유리한 조건만 테스트했다.** 세 라운드 다 테스트 파일을 미리 줬다 —
   게이트가 완전 명세된 상황이다. 토너먼트가 값을 한다면 그건 **명세가 모호하고
   접근법이 갈리는 태스크**일 텐데, 그건 이 벤치에 없다. **"동등"은 잘 명세된 태스크에 한정된 판정이다.**
2. **표본이 3개다.** 통계적 판정이 아니라 방향성 관찰이다.
3. **천장 효과.** 두 모델 다 100%를 쳤으니 게이트가 변별력을 잃었다. 더 어려운 과제였다면
   갈렸을 수 있다 — 라운드 2에서 RFC4180 엣지케이스를 넣었는데도 양쪽이 전부 맞혔다.
4. **diffSize 방향은 일정하지 않았다** — R1 codex 30 : grok 48, R2 codex 52 : grok 68, R3 codex 46 : grok 39.
   앞 둘은 codex가, 셋째는 grok이 더 간결했다. 즉 "누가 더 간결한가"는 과제마다 갈린다.
   타이브레이커가 실제로 작동한다는 증거이기는 하다.

**후속으로 값이 있는 실험**: 게이트가 느슨하거나 접근법이 여러 갈래인 태스크(리팩터링, 성능 최적화,
API 설계)에서 재측정. 단 그런 태스크는 채점이 어려워 토너먼트 가드(게이트 필수)와 충돌한다 — 이 긴장이
토너먼트의 근본 한계일 수 있다.

## 부수 발견 — 실제 결함 3건

### 1. `diffSize` 타이브레이커가 신규 파일에서 무력화됨 (수정 완료)

`git diff --shortstat`은 **untracked 새 파일을 세지 않는다.** 초기 채점에서 양 참가자 모두
`diffSize=0`으로 나와 동점 해소에 실패했다. 토너먼트의 주 사용처가 신규 파일 생성이므로
2순위 타이브레이커가 **항상** 죽는 결함이었다.

수정: `git add -A -N` 후 `git diff --shortstat HEAD`. 교정 후 codex 30 / grok 48로 정상 판별.
`references/execution-shapes.md` §5-3, §5-4, §5-5에 반영.

### 2. `grok` 바이너리 이름 충돌

이 머신에 `grok`이 2개 있다:

| 경로 | 정체 | 버전 |
|---|---|---|
| `~/.grok/bin/grok` | **공식 xAI Grok Build** | 1.0.4 |
| `/opt/homebrew/bin/grok` | 서드파티 `@vibe-kit/grok-cli` | 1.0.1 |

서드파티 쪽은 `--sandbox`/`--no-auto-update` 등을 모르므로 잘못 잡히면 실행이 깨진다.
`EXTRA_BIN_DIRS`가 `~/.grok/bin`을 PATH **앞**에 붙이는 순서가 공식 CLI를 결정적으로 이기게 하는
장치다 — `run-cli-job.js` / `run-cli-worker.js` / `check-env.js` 3곳에 주석으로 명시.
### 3. jobs-dir가 측정 대상 워크트리를 오염 (수정 완료) — **실기에서만 드러남**

`--jobs-dir`를 워크트리 안(`<worktree>/.jobs`)에 두면 `job.json`·`output.txt`·`error.txt`가
`git diff`에 섞인다. 라운드 3 실측에서 codex의 stderr 779줄이 실제 코드 46줄을 덮어
**diffSize가 858로 잡혔고, 타이브레이커가 코드 품질이 아니라 로그 수다스러움으로 승자를 갈랐다.**

수정: (a) jobs-dir를 워크트리 **바깥**(`${ARENA}/.jobs/${provider}`)으로, (b) 측정을
소스 경로로 좁힘(`git diff --shortstat HEAD -- src lib app`).

이 결함은 단위 테스트로는 잡히지 않는다 — 실제 CLI를 돌려 실제 로그가 쌓여야 나타난다.
